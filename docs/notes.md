# ESCAPE — エリア1 メモ正文（docs/notes.md）

本書はゲーム内の壁メモ・掲示の**正文**である。実装時は一字一句変更禁止（改行位置の調整と、`{PLACEHOLDER}` 形式の置換のみ可）。
執筆・改訂はメインセッションのみ。ヒントの整合（仕掛け順序・コード・場所）を変える場合は本書を先に改訂する。

## エリア1の仕掛け連鎖（実装仕様・P4向け）

順に解くと次エリア扉（南東の隔壁）が開く。

1. **仕掛け1「非常電源」**（機械室）: 主電源盤のレバーを「調べる」で投入。大きな駆動音が鳴り（ESCAPE.noise.emit・敵が調査に来る）、制御室の端末が起動する。
2. **仕掛け2「隔壁解錠コード」**(制御室): 起動した端末にコード **2739** を入力。コード自体は記録室のメモ（memo4）に記されている。入力UIは4桁のテンキー。
3. **仕掛け3「手動開放ハンドル」**（隔壁前）: 解錠後、隔壁のハンドルを長押しで回す（3秒）。回している間も大きな音が鳴り続ける。開放で次エリアへ。

## 掲示（短文・使い回し可のフレーバー）

- `立入禁止 B-3実験区画` / `除染後に退出すること` / `走行禁止` / `警報作動中`
- 隔壁前: `非常隔壁 手動開放は解錠後のみ可 / 開放中は大音響に注意`
- 制御室端末（未通電時）: `NO POWER`
- 制御室端末（通電後）: `隔壁解錠コードを入力してください`

## UI文言（調べる系）

- メモ接近時: `メモを読む`
- ロッカー: `隠れる` / 中から `出る`
- 板: `板を倒す`
- 主電源レバー: `レバーを投入する`
- 端末: `端末を操作する`
- 隔壁ハンドル: `ハンドルを回す（長押し）`
- 牢の格子: `格子をこじ開ける（連打/長押し）`
