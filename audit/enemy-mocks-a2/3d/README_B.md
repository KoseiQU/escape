# レーンB — 案F「寄り集まった亡骸」質上げ（P5e-1）

対象ファイル: `mock_F.js` / `index_b.html` / `F_full.png` `F_face.png` `F_corridor.png`

前回のメイン判定は **「骸骨の飾り物」**。原因は ①骨が清潔で均一な黄色 ②白く揃った歯
③眼窩が浅い ④皮膚や腱が無い ⑤部品が玩具のように整っている ⑥照明が平坦。
本稿はモデルとハーネスの両方を作り直した。

## 共通改善点（DESIGN.md §4 P5e-1）への対応

### 1. 頭部は頭蓋から積む・左右非対称
- 頭蓋は `F.skull()` で一体彫り。球を変形して **額を後ろへ寝かせ**（`shape()` の
  `rz*0.34*up²*fw`）、顔面へ向かって幅を絞り、下方を絞って上顎へ繋ぐ。
- 別パーツで積んだもの: 眼窩の縁（楕円リング）／眉弓／頬骨弓（殻から浮かせて下に隙間）
  ／上顎（歯槽突起）／下顎（U字の管＋下顎枝＋下顎頭）／頸椎。
- 稜と窪みは `A2LIB.ridge` / `A2LIB.bulge` で彫った: 矢状・冠状・ラムダの3縫合、側頭線、
  側頭窩、前頭隆起、後頭隆起、鼻根、眼窩の上縁・外縁・下縁。
- **非対称**: 左の側頭窩を右より深く（-0.027 / -0.0215）、左の眉弓は途中で欠ける、
  左右の眼窩で大きさ・高さ・傾きを変える、頭頂と後頭に欠損を1つずつ。

### 2. 眼窩は黒い空洞・骨の縁が立つ
- **三角形を削って本当の穴を開けた**（`F.punch()`）。窪みを彫るだけでは光が回って
  「浅い皿」に見えたため。眼窩2つ＋梨状口（3つの楕円を重ねて洋梨型）を貫通させた。
- 穴の奥は頭蓋の内殻（外殻と同じ変形をかけた 0.90 倍の殻）と円筒の内壁で塞ぐ。
  どちらも **MeshBasicMaterial の純黒**＝照明の影響を受けず必ず黒く落ちる。
- 穴の周囲は隆起で縁を立て、さらに細い楕円リングで切り口を隠した。眼球は無い。

### 3. 皮膚・骨の質感（一様色と金属光沢の禁止・metalness 0）
- 骨のアルベドを新規に描き起こした（`boneCanvas`）: 低周波の色ムラ＋細かい斑の
  **汚れた黄褐色** に、泥と黴のこびりつき（低周波の塊）、黒ずんだ縦の垂れ、
  枝分かれする **ひび** 95本、剥がれて明るく出た新しい骨面、栄養孔と粒状感。
- そこから Sobel で法線・粗さを起こす（`F.maps`）。粗さは明部 0.58〜0.60 /
  暗部（汚れ・ひび）0.94〜0.98。全マテリアル metalness 0。
- 骨は3系統（通常／汚れの強い個体／子供の細い骨）＋羊皮紙状の乾いた皮膚（`dryCanvas`:
  黄ばみ・腐って黒ずんだ部分・縮れた皺・透けた血管）。

### 4. 人体の部品を3つ以上
歯列（1本ずつ独立ジオメトリ・6色から選択・大きさと向きを散らし、20〜28%を欠損）／
肋骨（2組・折れた肋骨を16%混入）／椎骨と棘突起／鎖骨／腱（`F.sinew`）／
指の節（手5・足4、各5指×3節）／下顎頭／骨盤。

### 5. シルエット: 多すぎる肢と複数の頭蓋
（2026-09-14 ユーザー目視差し戻し「もっと顔の数を増やして複雑に」を反映して増量）
- 頭蓋 **8個**（＋断片2）。大きさ・状態・向きを全部変えてある:
  1 **主**＝首をねじって壁の外（カメラ側）を向き、下顎が横へずれて開く（seg 52・唯一の高密度）
  2 肩の乾いた肉に半分埋没 3 背中側に逆さで沈む 4 子供（0.62倍・胸郭の縁から覗く）
  5 欠けた半分（下顎なし・欠け 2.6倍・下の肋郭に食い込む） 6 幼児（0.48倍・腰の骨の間）
  7 大人（0.80倍・胸郭の左から顔を出す） 8 子供（0.56倍・腰の下から出る）
  ＋ **下顎だけの断片**（骨盤の上に癒着）／**頭頂の割れた蓋**（背中から生える）
- 肋郭 **3つが噛み合う**（大人＋60°回した小胸郭＋子供の小さい胸郭）。
- 肢は **12本**。大人7・子供4・前腕と手だけ1。うち **2本は逆向きに曲がる**
  （肘が手前へ折れて前腕が壁へ戻る／膝が前方へ折れる）。加えて手首から先が無い折れた腕1本。
- **一体化**: 脊柱に沿って乾いた組織の鞘を2本通し（`core` / `core2`）、埋没した頭蓋ごとに
  歪めた肉のかたまり（`F.warpBall`）、下胴に大きな肉塊2つを置いて
  「背骨1本の芯に全部が癒合した一体の怪物」としてまとめた（骨の山に見えないように）。
- 壁（x=+1.00 の面）に手5本・足4本を掛けて這う姿勢。指は掴む向きに曲げてある。

### 6. 撮影
- ナトリウム橙のキー1灯（斜め上・画面外）＋水面の緑のリム（下・背後）＋ごく弱いフィル。
  背景はほぼ黒、薄い霧（FogExp2）。金属光沢のブロブを避けるため室内視点の水面板は外し、
  緑は照り返しの光だけ残した。
- 3視点: `?m=F&v=full` / `v=face` / `v=corridor`。
  corridor は **幅1マス（2m）・天井2.4m の煉瓦支線**に灯具を置かず、奥の合流部と
  背後（プレイヤーが来た方）からの弱い漏れだけで撮る。カメラ距離 8.7m。

### 髪・布・根
主頭蓋の頭頂から濡れた髪の房9本、2つ目の頭蓋から5本。腐った布の切れ端3枚（歪ませた面）。
壁から這い出た白い根6本が骨に絡む。

## 既知の妥協点
- 眼窩の穴は三角形単位の切り取りなので、切り口は厳密な楕円ではない（縁のリングで隠している）。
- 頭蓋3つは同じ彫り方の使い回し（seed と欠けの強さ・分割数だけ変えている）。
  主頭蓋のみ 52 分割で、他は 24〜34 分割＋`slim`（頬骨弓・皮膚片・腱を省略）。
- 皮膚は膜（三角パッチ）・歪めた楕円体・殻の断片で表現しており、骨に張り付いて垂れる襞までは作っていない。
- 下半身の肢が放射状に広がるため、全身視点の下側はまだ骨の束に見える余地がある。
- 増えた頭蓋のうち下側の3つ（幼児・下顎断片・子供）は full 視点では小さく、数えるには寄りが要る。
- 血・粘膜は入れていない（乾いた骸という設定のため）。
- ポーズは固定。壁への接地は座標を手で合わせている（物理的な接触判定はしていない）。
