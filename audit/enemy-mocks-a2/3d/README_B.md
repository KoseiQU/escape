（エリア1の女性的な敵との対照）。本番と同じ構法——顔はジオメトリで彫る／テクスチャの絵付けで
顔を作らない／眼球にハイライトを入れない／材質はプロシージャルの法線（bump）＋粗さ。

## 3案の狙い（各3行）

### 案F 寄り集まった亡骸 — 30,017 三角形
- 3体の骸が癒合した性別不明の個体。主体の右腰に2体目、左肩に3体目の胸郭断片が生えている。
- 腕6本・脚4本が長さも太さも向きもばらばらで、癒合部は皮膚が引きつって襞と血管になる。
- 頭蓋3つ。1つだけ正面を向いて口を開き、あとの2つは肉に半分埋没して傾いている。
- 恐怖の核: 「何体いるのか数えられない」こと。顔の寄りで正面の頭蓋と埋没した頭蓋が同時に入る。

### 案G 皮を剥がれた巨躯 — 17,373 三角形
- 2.6m の筋肉質の男。皮膚が無く、筋束を1本ずつ積んで濡れた赤黒と黄色い脂肪の層を作る。
- 下顎が千切れ（折れ口と咬筋の残骸つき）、舌が喉から胸まで垂れる。眼は白濁したまま残る。
- 低い天井の支線（配管）に片手で掴まり、肩をすぼめて立つ＝「ここは狭い」が絵で分かる。
- 恐怖の核: 質量と生々しさ。逃げ切れそうにない体積を、暗がりでも濡れた反射で見せる。

### 案H 顔のない管理者 — 14,140 三角形
- 2.4m の細い男。防護服の残骸（フード・前面ジッパー・裂けた裾・ゴム手袋の名残）。
- 顔が無い。錆びた面体・フィルター缶2つ・蛇腹ホース・バルブが癒着し、縁で皮膚が盛り上がる。
- 体は 49° 捻れたまま、首だけこちらへ回している。指先は金属化して錆びた爪になっている。
- 恐怖の核: 静けさと「元は人だった」痕跡。表情が読めないので何を考えているか分からない。

## 構法のメモ（本番に引き継ぐ）

- **頭蓋は1枚の球ではない**。脳頭蓋は額から上だけの殻（`thetaLength 0.44π`）にし、後頭・頭蓋底は
  後ろ半分だけ（`phiLength π`）にして**顔面を開けておく**。そこへ眉弓・眼窩縁・頬骨・頬骨弓・
  鼻骨・上顎・口蓋・歯（1本ずつ）・下顎体＋下顎枝を別パーツで積む。
  球をそのまま使うと顔面が smooth な覆いで塞がり「お面」になる（案Fで実際に一度失敗した）。
- **眼窩は実際の空洞**。内向きの円錐（`ConeGeometry` を `rotation.x = π/2`）を彫り、材質は
  `MeshBasicMaterial`（ライティングを受けない黒）。`MeshStandardMaterial` の黒だと DoubleSide の
  裏面が法線反転で照らされ、空洞が「明るい窪み」に見えてしまう。
- **筋は紡錘形の筋束を積む**（案G の `bundle()`）。1本の円柱では「棒」に見える。
- **癒着・裂け目は別パーツ**（リッジ＋めくれ＋血管）。面の色だけで表現しない。
- `Object3D.add()` は**追加した子ではなく親を返す**。`parent.add(mesh).rotation.z = ...` と書くと
  親（＝体全体）が回る。案Hで実際に体が 23° 傾き、頭の world 座標が (0,2.25,0) から
  (-0.57,2.07,0.66) までずれた。ヘルパーの `add()` は子を返す実装にしてある。

## 既知の妥協点

- **アニメ無し・ポーズ固定**（段階0の仕様どおり）。リグも入れていない。選定後の段階1で組む。
- 皮膚・筋の陰影は bump（法線マップ相当）＋粗さのみで、AO を焼いていない。凹部の締まりは本番で要改善。
- 案Fの手足の指、案Gの足指は簡略（節2〜3）。寄りに入らない前提で分割数を落としてある。
- 案Gは筋束の境目が溶けて「葡萄の房」に見える箇所がある。本番では筋膜の溝（暗い細い谷）を入れたい。
- 案Hの防護服は布の垂れを表現していない（剛体のフラップ）。本番では裾と袖に簡易な布の曲面が要る。
- 舞台の明るさは全身で中央値9前後と暗い。合格済みの `audit/enemy-mocks/v4_face.png`（中央値9）と
  同水準でレーンAとも揃えてあるが、印刷やモニタによっては暗く見える。判定は暗い部屋で。
